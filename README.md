## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Visual Studio Code

## Run the website

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in your browser, or use the Live Server extension.
3. Visit each page through the navigation menu.
4. Resize the browser to test the mobile layout.

## Project structure

- `css/variables.css` — Design variables
- `css/reset.css` — Browser style reset
- `css/global.css` — Global styles
- `css/layout.css` — Shared page layout
- `css/components.css` — Reusable UI components
- `css/home.css` — Home page styles
- Other page-specific CSS files — Styles for individual pages
- `js/script.js` — Mobile navigation and footer year
