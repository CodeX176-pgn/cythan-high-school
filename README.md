# Cythan High School website — starter

A beginner-friendly fictional school website homepage built with HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `cythan-high-school` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Resize the browser to test the mobile navigation.

## Project files
- `index.html` — homepage structure and content
- `css/style.css` — colors, layout, and responsive design
- `js/script.js` — mobile menu and current year

## Important
Cythan High School is fictional. All sample announcements, dates, and contact information are placeholders. Replace them with assignment-approved content if needed.
